# Pseudo-Professional Jargon Reduction Map

Use concrete code objects, actions, and measurements instead of abstract engineering buzzwords. Only keep a term when it is a literal domain/protocol name (for example, CSS alignment or memory alignment).

| Abstract Jargon | Plain Engineering Replacement |
| :--- | :--- |
| 对齐 / 对齐口径 | 改一致 / 照着改 / 统一字段名 |
| 边界 / 语义边界 | 范围 / 限制 / 输入条件 |
| 链路 / 主链路 | 流程 / 调用路径 / 请求过程 |
| 闭环 / 最小闭环 | 跑通 / 完整流程 / 最小可用版本 |
| 兜底 | 备用方案 / 失败回退 / 默认值 |
| 收敛 | 稳定下来 / 缩到 / 定下来 |
| 能力 | 功能 / 支持做 X |
| 前端侧 / 服务端侧 | 前端 / 服务端 / 手机上 |
| 显式 / 隐式 | 直接写明 / 自动带入 |
| 形态 | 样式 / 结构 / 做法 |
| 契约 | 接口约定 / 字段格式 |
| 可观测性 | 监控 / 日志 / 埋点 |
| 进行 / 实现 / 提供 / 确保 (虚化动词) | 直接用具体动词：改、加、查、跑、拦住、防止 |
